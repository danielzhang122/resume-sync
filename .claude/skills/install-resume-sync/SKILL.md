---
name: install-resume-sync
description: Set up the weekly résumé sync pipeline (LaTeX résumé kept in line with a person's GitHub repos via cited PRs, one-page CI check, scheduled agent) in someone else's résumé repo. Use when asked to install, copy, set up or adapt this résumé pipeline for another person or repo.
---

Follow `INSTALL.md` at the root of this repo, step by step. It covers gathering the person's
settings, converting their résumé to LaTeX if needed, running `scripts/install.py`, verifying the
build, and scheduling the weekly agent. Confirm with the person before creating repos, pushing to
their `main`, or scheduling the task.
